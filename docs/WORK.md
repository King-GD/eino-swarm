# 工作记录

打开桌面或 Web 会话后，右侧栏提供「工作记录」。标签出现时保留当前焦点。「当前会话」展示本会话的私有记录及当前项目的共享记录，「整个项目」只展示共享记录。独立会话只使用会话范围。未选会话时，启用女娲或已有共享记录的项目仍可从项目入口打开。工作记录和女娲的模型编排分别见 `C-055` 与 [Nuwa](NUWA.md)。

## 记录与合并

| 类型 | 状态 | 默认值 |
| --- | --- | --- |
| `task` 任务 | `pending`、`running`、`done`、`blocked`、`cancelled` | `pending` |
| `fact` 事实 | `reported`、`superseded`、`retracted` | `reported` |
| `artifact` 成果 | `reported`、`superseded`、`retracted` | `reported` |

Agent 通过 `record_work` 写入。创建需要 `kind` 和 `title`，默认 `scope:"thread"`。更新需要现有 `id` 和当前 `version`，省略的字段及范围沿用原值，空证据或依赖数组清除原引用。成果路径须指向会话文件范围内已有的普通文件。保存路径只保存引用。

`scope:"project"` 可以创建共享记录。已有记录用 `id`、`version` 和 `scope:"project"` 合并，或者在详情中点击「合并到项目」。这两种动作都会在同一事务中合并所需的会话私有前置依赖，并核验全部相关引用。写入冲突时先刷新。共享后记录和原身份留在项目，范围可以从会话提升到项目。已有的旧版记录在升级时归入项目范围。

会话记录的证据引用该会话内已有事件，项目记录的证据引用当前仍属该项目的会话事件。按 `thread_id` 和 `seq` 定位事件，提供 `turn_id` 时也要匹配。也可用 `own_tool_call_ids` 引用当前经理回合或同一 worker 执行中自己的持久工具回执。最多 16 个，须各有唯一且有序的调用和结果。保留的 worker 跨经理回合继续使用原执行范围，恢复后的新执行有自己的范围。`own_tool_call_ids` 与 `evidence` 互斥，省略两者保留引用。工作工具的结构化调用和结果留在所属会话的历史中，项目证据应引用原始事件。记录和证据链接是带来源的报告，业务验收仍由实际验证完成。

会话移动后保留私有记录，共享记录留在原项目。项目证据移出归属或因编辑重发消失时，界面标示来源不可用。删除会话清理它创建的记录及版本，其他作者的引用仍可查看失效状态。

## 查看与修正

`read_work` 分页列出可见记录，按 ID 读取详情、依赖版本、证据和记录者。工具结果遵守既有字符预算。面板使用实线表示已登记的依赖，虚线表示到目标的图形连接。相同类型且无依赖关系的多条记录共享一行，展开后可查看和筛选。点击路径节点会突出其上下游，点击详情可以跳到来源会话的 Trace 或打开成果。记录者和模型按实际会话、回合、worker 和 generation 匹配。worker 状态来自持久生命周期；记录任务完成与引擎收取 worker 结果是两个动作。

已否定、已撤回、已取代或已取消的记录仍能在详情和 `read_work` 中找到。没有有效下游的失效记录默认收进一条可展开的汇总，有有效下游的记录留在路径上并变淡。「显示已剪枝」可临时展开完整图。证据改变时应更新同一条记录及依据；事实或成果重新成立时，用当前版本改回 `reported`。记录随下次快照返回图中。依赖的版本变化仍需下游通过 `depends_on` 显式重新确认。

## 模型预览与设置

宿主按回合冻结工具配置。Settings → Swarm 的 `work_ledger` 默认开启，关闭影响后续普通回合的自动工具和预览。女娲、面板读取和用户合并仍可用。规划回合只提供 `read_work`。

普通回合有记录时，模型请求收到当前可见范围的短预览，女娲回合也会收到空快照。worker 优先看到与当前执行任务相关的报告，经理优先看到近期更新。失效记录只保留 ID、类型、标题、状态和版本，预算不足时优先略去。保留的有效记录依赖因预算省略的有效前置记录时，前置链仍可在 `path` 中显示。工具结果字符限制计入说明和完整 JSON。同一模型请求已包含匹配两侧 revision、版本和状态的工作工具结果时可省略重复预览。读取失败或归属变化以不可用状态显示。完整详情仍可分页读取。预览只进入当前模型请求，聊天历史、压缩输入和 fork 上下文保留原内容。

接口、版本和测试见 [API](API.md)、[数据模型](DATA_MODEL.md) 和 [测试](TESTING.md)。
