# zwai 对话工作台组件规范 · 第一版

这版覆盖桌面和网页的侧栏、首页、主输入框与三个选择菜单。侧栏用底色差区分正文，图标线宽 1.5px。调宽热区为 8px，悬停和键盘聚焦只显示 1px 指示线。尺寸集中在 `frontend/src/styles/workbench.css`，字号跟随应用的界面字号设置。

| 组件 | 外观和布局 | 交互 |
| --- | --- | --- |
| 侧栏 | 窗口控制区下方依次放 zwai、新对话、搜索和业务导航。项目或对话列表占中间，设置和账号固定在底部。 | 新对话是动作；当前所在的导航行使用浅色底。收起后保留图标。顶部按钮位置固定，标题栏与侧栏共用一条连续的细分隔线，同步收放；开启减少动态效果时直接切换。 |
| 导航行 | 默认高 34px，左右内边距 10px，图标与文字相距 10px，圆角 7px。 | 悬停显示底色。新对话和搜索的快捷键在悬停或键盘聚焦时显示。 |
| 首页 | 新对话标题栏留空，首页按已登录账号显示问候。问候、输入框和建议作为一组在对话区内居中，主区右缘直角贴合相邻面板或窗口。建议任务下方的 FOFA 地球贴底露出上半球，使用原球面纹理缓慢自转并显示城市波纹；开启减少动态效果时固定当前视角，搜索框采用 96° 蓝青渐变细边和 FOFA 搜索图标，浅色从蓝到青，深色从青到蓝。搜索按钮为 28px，使用官网 22px 字形，距右 19px、距底 12px。首页输入框的右侧留白取整，避免放大镜落在半像素上而变淡。空草稿显示完整图标，发送仍禁用。建议任务在输入框下方排成一行，窄窗口可换行。 | 点建议将内容填入草稿，由用户发送。 |
| 输入框 | 输入和工具共用一块表面。附件、工具和思考靠左，模型、上下文用量、语音和发送靠右。同一行的图标、标签和操作沿垂直中心对齐。 | 焦点切换时外框稳定。运行中的停止、排队和引导仍使用原有入口。 |
| 选择菜单 | 工具按钮默认高 30px、圆角 7px，菜单圆角 12px。菜单与触发按钮相距 4px。 | 有空间时盖在草稿上，保留工具条供切换。一次只开一个菜单。模型和思考为单选，工具支持连续勾选，Esc 关闭。 |
| 对话过程 | 标准模式下正文和续写框共用最大 760px 的阅读列，宽屏模式填满对话区。用户消息靠右，回答、步骤和完成时间靠左。轮次之间留出 24px。 | 点击步骤可展开，子代理可直接打开。上翻后有新内容时，回到最新消息的按钮在输入框上方居中。 |
| 等待与结果 | 子代理等待行显示当前这次等待的成功数和总数，名单默认收起，展开时按名称、状态和耗时对齐。等待结束时同一行切换图标，可展开查看该次调用的记录。已完成答复突出 Markdown 标题，并在末尾集中列出正文引用的工作区文件。 | 点击子代理进入详情；点击文件打开原有预览。超过四个文件默认折叠。文件下方同一行放置原有答复操作与完成时间，窄窗口可换行；已完成答复下常显复制与朗读入口，超过一屏时还可直接跳回答复开头。 |
| 普通操作 | 首页、账号和设置里的文字按钮与菜单项跟随 UI 字体、字号和行高。 | 指向可用操作时显示手形、浅青底和青色文字；按下时底色加深，键盘聚焦显示轮廓。按钮保持原位，浮层使用阴影。退出账号使用危险操作色。 |
| 设置页 | 左侧为设置分类，右侧为当前分类的设置项。窄窗口将分类收进顶部选择器，较长的表单控件放到说明下方。浅深主题共用行距、控件高度、选中与聚焦样式。 | 分类支持方向键、Home 和 End，搜索继续按原规则过滤。 |
| 色彩 | 正文和普通导航使用中性色，FOFA 青用于品牌、主操作和选项反馈。 | 当前项同时有背景、文字或勾选标记，键盘聚焦有轮廓。 |

对一项尺寸或状态做调整时，在同类组件上一起试。验看至少包含空白首页、运行中的底部输入框、完成后的会话，以及展开和收起的侧栏。
